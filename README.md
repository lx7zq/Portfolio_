# Portfolio

Portfolio Website พัฒนาด้วย Vue 3 และ TypeScript 

## Tech Stack

- Vue 3
- TypeScript
- Vite
- Tailwind CSS
- PrimeVue
- Vue Router

## Features

- Responsive Design
- Project Showcase
- About Me
- Contact Section

## Installation

```bash
bun install
```

## Development

```bash
bun dev
```

## Build

```bash
bun run build
```
